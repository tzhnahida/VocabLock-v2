# VocabLock 文档索引

本目录记录 VocabLock 的设计、审计、工程日志与决策依据。代码仍是唯一事实来源；文档与代码冲突时，以代码为准，并回头修文档。

| 文件 | 内容 |
|---|---|
| docs/AUDIT-2026-11-10.md | 全量代码审计（已实现/半成品/死代码/风险/修复顺序） |
| docs/DESIGN.md | 新界面原型说明、设计 token、打开方式 |
| docs/ENGINEERING-LOG.md | 追加式工程日志：完成/方法/踩坑/失败/原因/剩余/规划 |
| docs/STATUS.md | 当前状态、未完成清单、下一步顺序 |
| docs/design/app.html | 可交互原型（双主题 + 中英日） |
| docs/design/screenshots/ | 验收截图（首页/答题/词库/锁屏） |

## 维护规则

1. AUDIT 是时间点快照，不追改历史；新审计另建文件（如 AUDIT-YYYY-MM-DD.md）。
2. ENGINEERING-LOG 只追加，最新条目放最上面；不删除旧条目，除非明确作废并标注。
3. DESIGN 记录已确认的视觉方向；用户改主意时更新并注明日期与原因。
4. 每个条目必须能回答：做了什么、怎么做的、哪里失败、为什么失败、还剩什么、下一步是什么。
5. 不把密钥、token、真实用户数据写进 docs。
