## D. 明确决策（不要再改回去）

1. 时间额度按题型固定单位累计，不按真实挂钟。
2. 题数或时间额度满足即完成；准确性门槛保留在题数完成路径。
3. 计划在 session/start 时确定，不在出题过程中临时重算。
4. SM-2 决定能不能出这个题型，AI plan 决定出多少比例；不用“本轮第几题”硬切阶段。
5. 语法题只来自 grammar_points，不由词题型随机生成。
6. 成熟词才进入逐词沉浸；不按单词切换整个 UI 语言。
7. 句子 TTS 学完即删；单词 TTS 按使用次数淘汰。
8. 启动直接全屏落在目标屏，不要求用户点最大化。
9. 续点：学习卡按索引恢复；练习按已答数量/配额恢复，不保证原题顺序。
10. AI 失败不能把用户锁死：能回退就回退，不能回退就完成并解锁。

## E. 回归验收清单

### 配额/会话
- [ ] 15 题目标、12 词可用 → 自动扩 3 词后继续，而不是停在 12。
- [ ] 无 AI → 12 词做完后显示完成，不提示导入。
- [ ] 题数达标或时间额度达标 → 解锁。
- [ ] 中途关闭 → 学习卡从保存索引继续。
- [ ] 学习完成后重开 → 直接练习。
- [ ] 练习中途关闭 → 不从第 1 题重来。

### 出题
- [ ] 新词不出现 reading_comp / 长朗读 / 语法。
- [ ] 语法题只围绕 grammar_points。
- [ ] 填空上下文太短被拒绝。
- [ ] 填空题显示方向提示。
- [ ] 造句含未学词 → 重试/回退，不直接出。

### 窗口
- [ ] 启动直接第二屏全屏，无需点击。
- [ ] 锁定期间关闭/最小化/缩放无效。
- [ ] 解锁后三个按钮可恢复。

### 发音
- [ ] 音素分数存在时，总分与音素平均一致。
- [ ] 读单词不再被当成“输入读音”题。

### TTS
- [ ] 常用单词音频不会被预生成冷门词挤掉。
- [ ] 句子音频播放后文件被删除。

### 沉浸
- [ ] reps>=4 且 interval>14 的词默认目标语释义。
- [ ] “显示中文”可回退。
- [ ] 不成熟词仍显示中文。
