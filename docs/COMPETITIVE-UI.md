# 竞品 UI 与学习方式调研

调研时间：2026-11-20 · 范围：Duolingo、Anki、Quizlet、Memrise、LingQ、WaniKani、Bunpro、墨墨背单词 / 百词斩 / 不背单词
目的：回答两个问题——别人的 UI 为什么“丝滑”，别人的学习流程为什么“顺”；VocabLock 该抄什么、不该抄什么。

## TL;DR

1. **首页只回答一个问题：现在点哪里。** Duolingo 把首页改成一条 path，只有一个当前节点可点；VocabLock 首页是 8 个等权卡片，用户要先做信息架构题。
2. **流程是“认 → 练 → 考”，不是一上来考。** Quizlet Learn、墨墨都是先给词/信息，再自评/出题；VocabLock 之前新词直接出填空，是流程问题，不是 UI 问题。
3. **反馈是主角，不是页脚。** Duolingo 答完题整块变绿/红 + 音效 + 动画 + 自动下一题；VocabLock 之前只有一行 12px 小字。
4. **动效要短、要少、要同向。** 主流 150–250ms、4–8px 位移、一个缓动；我们的问题是“没有动效”而不是“动效不够炫”。
5. **进度必须可见。** streak / XP / 每日环 / 单词状态色（LingQ 蓝黄白）都是低成本、高反馈的设计。
6. **内容优先，chrome 退后。** Memrise 让视频/真人占满屏，LingQ 让文章占满屏；我们的卡片边框和标题占了太多注意力。
7. **高密度工具不靠“好看”。** Anki / Bunpro 的 UI 很朴素，但键盘流、稳定布局、少跳转；不要盲目抄它们的视觉。

## 1. 竞品拆解

### Duolingo

**UI**
- 首页是一条纵向 path：单元标题 + 圆形节点 + 当前节点唯一高亮，其他节点灰/锁；底部导航只有 5 项。
- 课程页：顶部细进度条、中央一道题、底部固定主按钮（未作答时置灰）；答完立刻整块反馈 + 角色动画/音效，再自动进入下一题。
- 游戏化：streak、XP、heart、league；数字都在“下一步”附近，不抢主操作。

**学习方式**
- path 的课程顺序由间隔重复驱动，练习内置在路径里；错题会回到路径中再练。
- 官方 redesign 文章明确说：目标是让用户不用思考“我学得对不对”，跟着路径走即可。

**可抄**
- 单一主 CTA + 路径化今天；答题页一屏一任务；反馈即动画；主按钮固定在拇指区。

**别抄**
- 过度游戏化（hearts 惩罚、league 焦虑）不适合工具型桌面应用。

来源：[Duolingo 官方 redesign 文章](https://blog.duolingo.com/new-duolingo-home-screen-design/)

---

### Anki

**UI**
- 极简：正面 → 翻面 → 四个评分按钮（Again/Hard/Good/Easy）；桌面端信息密度高、视觉陈旧。
- 优点：键盘流极快（空格翻面、1–4 评分）、布局稳定、不打断；缺点：初次配置和学习成本高，反馈弱。

**学习方式**
- 用户自建卡片 + SM-2/FSRS 调度；主动回忆；完全可控。

**可抄**
- 键盘操作不抢焦点、评分按钮语义清楚；复习界面“无干扰”。
- 评分即反馈：用户知道自己按了什么、下次何时见。

**别抄**
- 视觉密度和“数据库感”；桌面端不等于可以堆信息。

来源：[Anki 论坛关于复习界面顶栏的讨论](https://forums.ankiweb.net/t/the-style-of-the-review-interface/74241/4)

---

### Quizlet

**UI**
- Flashcard / Learn / Test / Match 多模式；Learn 模式先让用户设目标，再按掌握度自适应出题。
- 题型轮换：选择、书写、拼写；答错后要求重写正确答案；顶部有掌握进度。

**学习方式**
- Learn 根据目标与熟悉度生成个性化路径；错题回流；星标词优先。

**可抄**
- 开始前先定“今天学多少”；题型轮换；错题当场重做一次；进度条按掌握度而非题数。

来源：[Quizlet 帮助中心：使用学习模式](https://help.quizlet.com/hc/zh-cn/articles/360030986971-%E4%BD%BF%E7%94%A8%E5%AD%A6%E4%B9%A0%E6%A8%A1%E5%BC%8F%E8%BF%9B%E8%A1%8C%E5%AD%A6%E4%B9%A0)

### Memrise

**UI**
- 真人短视频 + 大字短语，界面 chrome 极少；学习像刷短视频，不像做题。
- 强调“当地人怎么说”，用面孔和场景建立记忆钩子。

**学习方式**
- 真实短语 + 视频 + 间隔重复；先理解场景，再回忆。

**可抄**
- 内容占屏、减少边框；用“人/场景”替代抽象词卡；短语优先于孤立单词。

**别抄**
- 视频加载成本与版权；桌面端不必做成短视频流。

来源：[Memrise 官网](https://www.memrise.com/)

---

### LingQ

**UI**
- 阅读器即主界面；单词按状态着色：蓝色=没见过、黄色=已收藏、白色=已知。
- 点词弹出释义，选完即时变色；顶部只保留“已知词数/金币”这类进度指标。

**学习方式**
- 可理解输入：在文章里点词、存词、隔几天再见；词汇状态逐步升级到 Known。

**可抄**
- 用颜色表达单词状态，让进度“可见但不用进统计页”；阅读/听力一体化。
- 单一进度指标（已知词数）比一堆图表更有驱动力。

**别抄**
- 满屏蓝色会制造焦虑，首次使用需要引导“先点几个”。

来源：[LingQ 官网](https://www.lingq.com/)

---

### WaniKani

**UI**
- Level 仪表盘：当前等级、待学/待复习数量、进度条；课程页大字 + 记忆法（mnemonic）+ 例句。
- 品牌感强（紫色、角色、文案语气），但复习界面仍然一屏一卡。

**学习方式**
- Radical → Kanji → Vocabulary 的解锁链；SRS 阶段；用记忆法降低首次学习成本；等级门槛防止过载。

**可抄**
- 用“解锁/等级”表达长期进度；首次学习先给记忆法，再考。
- 待学/待复习两个数字放在首页最显眼处。

来源：[WaniKani 官网](https://www.wanikani.com/)

---

### Bunpro

**UI**
- 语法填空（cloze）为主，输入框 + 提示 + 进度；深色主题、信息密度偏高。
- “Ghost review”：错过的语法点会以 ghost 形式再出现，直到稳定。

**学习方式**
- 语法 SRS；填空回忆；错题 ghost 重练；按 JLPT 分级。

**可抄**
- 错题“幽灵重练”机制；填空 + 提示的轻量交互。
- **别抄**它的文字密度和窄屏拥挤——这是“功能正确但不好看”的典型。

来源：[Bunpro 官方 how to review](https://api.bunpro.jp/support/getting-started/how-to-do-reviews)

---

### 墨墨背单词 / 百词斩 / 不背单词

来自少数派横向评测的要点：

- **墨墨**：先显示单词让用户回忆 → 点开信息页 → 自评“认识/模糊/忘记”；按点击与停留时长建立记忆矩阵，安排复习。效率高、界面偏干。
- **百词斩**：图片联想 + 选择题，轻松但容易“记住图没记住词”。
- **不背单词**：真实例句/语境优先，沉浸感强。

**可抄**
- 先回忆再揭示（active recall），自评三档比二值对错更细腻；
- 例句/语境优先，图片只做辅助；
- 学习节奏要“可感知”，不是纯算法黑箱。

**别抄**
- 纯图片记忆；过度依赖选择题。

来源：[少数派：5 个维度、6 个 App 背单词横评](https://sspai.com/post/87587)

## 2. 共性：所谓“丝滑”到底是什么

| 维度 | 主流做法 | VocabLock 现状 | 差距 |
|---|---|---|---|
| 主操作 | 一屏一个主按钮，固定底部/右侧 | 首页多卡片等权，答题页按钮在右下 | 用户要寻找下一步 |
| 流程 | 认→练→考，错题回流 | 已有学习卡，但题型顺序之前会跳考 | 已修，需继续收敛 |
| 反馈 | 整块色块 + 图标 + 音效 + 自动前进 | 已放大反馈，仍靠按钮进入下一题 | 缺自动前进/声音 |
| 动效 | 150–250ms，位移 4–8px，同向 | 刚加 fade/pop，但页面级转场缺失 | 缺“连续感” |
| 进度 | streak/XP/环/状态色 | 有环和统计，但分散 | 缺一个主指标 |
| 排版 | 8pt 网格、3–4 级字号、留白大 | 卡片多、字号层级弱 | 视觉噪音 |
| 内容 | 字/句/视频占屏 60%+ | 卡片边框和标题占比高 | 内容不突出 |
| 空态/加载 | 骨架屏、插画、明确下一步 | 多为文字 | 显廉价 |

**动效参数建议**（可直接落地）：
- 时长：hover 120ms、按下 100ms、进场 180–220ms、反馈 200ms；
- 缓动：`cubic-bezier(.22,1,.36,1)`（已有）；
- 位移：4–8px，不要超过 12px；
- 同屏最多 2 个元素同时动；答对只动反馈块，不要整页抖。

## 3. VocabLock 对比结论

### 我们的优势（别丢）
- 桌面端 + 本地优先 + 锁屏专注，这是 Duolingo/Quizlet 给不了的；
- SM-2 + 时间预算 + 后台 AI 微调，调度层比大多数竞品强；
- 多语言内容包、TTS/ASR/词典可插拔；
- 数据完全本地，隐私叙事可以做成 UI 卖点。

### 我们的问题（按影响排序）
1. **首页没有“下一步”**：今日目标、连续、待复习、最近学过、作业、快捷操作、薄弱项全是卡片，视觉权重相同。
2. **流程不闭环**：学习卡 → 题 → 反馈 → 下一题之间缺少连续动效和自动推进。
3. **反馈仍偏“说明文”**：即使放大了，还是“读一段字”，不是“感受一个结果”。
4. **排版层级弱**：13px 正文 + 大量卡片标题，缺少 28/20/16/14 的明确层级。
5. **缺少长期进度叙事**：streak 有，但没有“距离下一个里程碑还差多少”的目标感。
6. **语言混排**：英文 assignment、raw key（reading/general）会瞬间破坏质感——这类问题比动画更伤。

## 4. 改造优先级（建议）

### P0（最值得先做，1–2 周）
1. **首页改成“今日路径”**：顶部一个大卡片 = 今天唯一主任务（继续学习/开始学习），显示 3 个节点：学习卡 → 练习 → 复习；统计降级到右侧。
2. **答题页统一 shell**：顶部细进度 + 题号；中间一题；底部固定主按钮；反馈出现后主按钮变“下一题”并支持自动前进（可在设置关）。
3. **反馈升级**：整宽色块 + 大图标 + 一句结论 + 正确答案；答对自动 600ms 后进入下一题（可撤销）。
4. **排版 token 化**：28/20/16/14/12 五级字号；卡片 padding 20；圆角 14；一屏最多 3 个卡片。
5. **清掉语言混排**：所有 raw key、英文作业、未本地化文案统一走 strings。

### P1（2–4 周）
- streak + 每日环 + “本周目标”三件套；完成 session 的庆祝动画（一次，不骚扰）。
- 单词状态色（新词/学习中/待复习/已掌握）贯穿词库、首页、答题。
- 骨架屏 + 空态插画；设置页分组折叠。

### P2（内容层）
- 例句/语境优先（不背单词路线）；可选的短视频/真人发音（Memrise 路线）；错题 ghost 重练（Bunpro 路线）。

## 5. 具体页面提案（可直接照着写）

### 首页
```
[今日路径]  ← 一张大卡，占左栏 2/3
  今天 · 12 / 20 题
  ● 学习卡 8 个新词   ✓
  ● 练习 12 题        ← 当前，唯一高亮按钮「继续」
  ○ 复习 2 词（明天）
[右侧] 连续 12 天 · 本周 108 题 · 薄弱项（折叠）
```
- 主按钮只有一个；其他入口用文字链接。
- 统计数字用 28px，标签 12px muted。

### 答题页
- 顶部：`返回 · 第 12 天 · 本轮 12/20` + 2px 进度条；
- 中部：题型 tag（11px muted）+ 词/句（56–64px）+ 选项（48px 高，圆角 12）；
- 底部：左侧“退出”文字，右侧 44px 高主按钮；
- 反馈：整宽 64px 高色块，左侧 32px 图标，右侧一句结论；正确 600ms 自动下一题。

### 学习卡
- 词 64px、读音 16px muted、释义 22px；
- 跟读按钮 44px 高，录音状态用波形/计时；
- “下一个”在跟读完成前 disabled + 一句原因。
